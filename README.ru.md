# Lalascaner

Telegram-бот и база рынка компьютерной техники Кыргызстана. Собирает объявления с **lalafo.kg** и
публичных **Telegram**-каналов и групп, с помощью **ИИ** (бесплатная локальная модель через Ollama, Groq или Claude) вытаскивает из текста конкретные
позиции (модель, состояние, цена), копит базу, считает рыночную цену каждой модели и присылает
в бот новые объявления **ниже рынка**.

## Текущий режим

Читаются оба источника: **lalafo** и публичный Telegram-чат **compshop_kg** (вступать в него боту не
нужно — читается публичная веб-версия). Сложные посты разбирает **ИИ на вашем Mac через Ollama**
(бесплатно); однозначные объявления разбирают правила. Если ИИ недоступен, бот не останавливается:
работает на правилах, а посты, которые ждут ИИ, разбираются позже, когда он снова отвечает.

Всё переключается в `.env`: `TELEGRAM_ENABLED`, `AI_ENABLED`, `AI_PROVIDER`.

## Что умеет бот

- **🔍 Поиск** — просто напишите модель, можно с фильтрами: `3060 12gb`, `ryzen 5600 до 10к`,
  `ddr4 16gb б/у`, `ноутбук 4060 от 50к до 90к`. Ответ: рыночная цена (медиана, б/у и новые отдельно,
  обычный диапазон) и объявления с листанием, сортировка «от дешёвых» / «сначала новые», выгрузка в CSV.
- **📦 База** — категории → модели (с медианой и числом предложений) → карточка модели: сколько сейчас
  актуальных объявлений, самое дешёвое по каждой версии (Palit Dual — от 20 000, ASUS TUF — от 27 000),
  все актуальные предложения и кнопка «🔔 Следить». Выгрузка рынка категории или всего рынка в CSV.
- **🔥 Сделки** — объявления за 48 часов, которые оказались дешевле всех актуальных, и до сих пор не проданы.
- **🔔 Уведомления** — такие объявления приходят сами. После `/start` вы подписаны на все сделки;
  можно сузить: `/watch 4070 до 60000`, или получать вообще все новые объявления по модели: `/watch new 5700x3d`.

| Команда | Что делает |
|---|---|
| `/search 3060 до 25к` | поиск, сначала новые |
| `/price 3060 12gb` | поиск, сначала дешёвые |
| `/db gpu` | база: категория |
| `/deals` | сделки за 48 ч |
| `/sell rtx 3060 12gb б/у` (кнопка «💰 За сколько продать») | цена и как быстро уходит |
| `/watch all` · `/watch 4070 до 60000` · `/watch new 5700x3d` | подписки |
| `/watches` | мои подписки (удаление кнопками) |
| `/export 3060` | объявления в CSV |
| `/channels` · `/addchannel @name` · `/delchannel @name` | Telegram-источники |
| `/stats` | размер базы, очередь, расход токенов ИИ |
| `/backup` | прислать файл базы данных (снимок .db; больше 25 МБ — частями, склеить: `cat файл.db.part* > файл.db`) |
| `/update` (кнопка «🔄 Обновить с GitHub») | подтянуть новый код и перезапуститься, без захода на сервер |

## Как это работает

```
lalafo API ─┐                          ┌─ правила (однозначные объявления)
            ├─► объявления ─► фильтр ──┤                               ┌─► рыночные цены
t.me ───────┘   (дедуп)      болтовни  └─ ИИ (Ollama / Claude)  ─► позиции ─┤
                                                                                   └─► «ниже рынка» ─► бот
```

- **lalafo**: внутренний JSON API сайта — «Комплектующие для ПК», «Настольные ПК», «Мониторы», «Ноутбуки».
  Новые — каждые 10 минут, полный обход — раз в сутки.
- **Telegram**: каналы через веб-ленту `t.me/s/…`, группы (по умолчанию `compshop_kg`) — через embed-виджет,
  с учётом дыр от удалённых сообщений и альбомов. Нужна публичность источника, авторизация не нужна.
- **Темы форума** — в группах с темами (Болтовня, Правила, Blacklist, Ищу/Обмен и т.п.) объявлений нет,
  только оффтоп и спам. `TELEGRAM_BLOCKED_TOPICS` в `.env` — id тем, которые пропускаются целиком, даже
  если текст похож на объявление. Узнать id: открыть тему в Telegram → «⋮» → Копировать ссылку — число
  в конце. Работает для прямых постов в теме; на многоходовые ответы внутри неё пока не распространяется.
- **ИИ**: пачка из 10 постов → строгий JSON. Модель заполняет характеристики, а **ключ модели строит код** —
  «RTX3060 12G» и «GeForce RTX 3060 12GB» гарантированно одна модель. Ноутбук и готовый ПК — всегда одна
  позиция, их видеокарта/процессор отдельно не записываются.
- **Защита от мусора**: цены ниже правдоподобных для категории (видеокарта за 512 сом) отбрасываются;
  репосты не дублируются; «куплю …» не считается продажей.
- **Рынок**: медиана, квартили, мин/макс за 60 дней, отдельно б/у / новые / все. Один продавец с повторами —
  одна точка, выбросы отсекаются.
- **Сделка = дешевле самого дешёвого актуального объявления.** Новое объявление сравнивается с теми, что
  висят на lalafo прямо сейчас (проданные/снятые отсекаются по полному обходу раз в 6 ч), в двух уровнях:
  - **модель** — чип + память, например RTX 3060 12GB: «самая низкая цена на RTX 3060 12GB»;
  - **версия** — производитель + серия, например Palit Dual: «самая низкая цена на эту версию» — чтобы
    дорогой ROG Strix не проигрывал дешёвому Palit.

  Не сравниваются: объявления того же продавца, репосты, нерабочие вещи, фейково дешёвые цены; новый товар —
  только с новыми. Нужно ≥3 актуальных объявления и отрыв ≥3% (для ПК и ноутбуков ≥5% — у них разная
  конфигурация). Отдельными моделями считаются RX 580 2048SP, GT 1030 DDR4, майнинговые P106.
  Уведомления — только по однозначно разобранным объявлениям (не прайс-листы). Всё настраивается в `.env`.
- **Экономия на ИИ**: режим `hybrid` (простые объявления — правила), фильтр болтовни, копирование разбора
  репостов, кэш промпта, большие очереди — через Batch API (−50%, только для Claude).

## Какие данные собираются

- **История объявления** (`listing_events`): появилось, смена цены (со старой ценой), смена текста, поднятие
  в ленте (платное «вверх»), пропало с lalafo (продано/снято), вернулось.
- **Интерес покупателей** (`listing_metrics`): раз в сутки, если изменилось, — просмотры, показы, в избранном,
  сколько звонили и писали.
- **Всё остальное от lalafo** (`listings.meta`): старая цена, торг, VIP/платное продвижение, координаты,
  параметры, рейтинг и скорость ответа продавца, «pro»-аккаунт. Телефон — только хэшем: хватает, чтобы узнать
  одного перекупщика под разными аккаунтами, сами номера не хранятся. У Telegram-каналов — просмотры постов.
- **Динамика рынка** (`price_history`): ежедневный снимок медиан по моделям.
- **Векторы** (`listing_vectors`, модель `bge-m3` в той же Ollama): смысл текста объявления. На них работают
  «🔎 Похожие» в уведомлениях, поиск по смыслу (когда точных совпадений нет), поиск перезаливов и оценка
  цены для редких моделей по похожим объявлениям. Модель скачивается сама; в `/backup` векторы не входят —
  пересчитываются.
- **«💰 За сколько продать»** (`/sell rtx 3060 12gb б/у`): рыночная цена и три варианта — быстро, по рынку,
  подороже — с долей объявлений, ушедших за неделю по такой цене. Считается по истории lalafo (кривая
  Каплана–Мейера: висящие объявления учитываются честно, перезаливы — не продажа). Точность растёт с каждой
  неделей сбора.

Сводка собранного — в `/stats`.

## Бесплатный ИИ (Ollama на вашем Mac)

Ollama запускает языковые модели локально. Модель нужна только для сложных постов (прайс-листы, «продам X,
куплю Y», нестандартные формулировки) — однозначные объявления бот разбирает и без неё.

**1. Установите и запустите Ollama** (не в Docker: контейнеры на Mac не видят GPU, а нативная Ollama
использует Metal и работает быстро):

```bash
brew install ollama
```
```bash
brew services start ollama
```

Вторая команда важна: без неё Ollama не запущена (`Error: could not connect to ollama server`) и не
поднимется после перезагрузки Mac. Проверить, что она отвечает:

```bash
curl http://localhost:11434/api/tags
```

Должен вернуться JSON. Если `Connection refused` — сервис не запущен; попробуйте `ollama serve` в отдельном
окне терминала или установите приложение с [ollama.com/download](https://ollama.com/download) (оно само
запускается при входе в систему).

**2. Скачайте модель** (один раз, несколько гигабайт). Сколько у вас памяти:

```bash
sysctl -n hw.memsize
```

Число делите на 1073741824 — получите ГБ. **16 ГБ и больше** — берите `qwen2.5:7b` (хорошо понимает русский
и работает со схемой ответа); **8 ГБ** — `qwen2.5:3b` (слабее, зато не будет тормозить вместе с Docker):

```bash
ollama pull qwen2.5:7b
```

**3. Укажите в `.env`** (в `.env.example` это уже стоит по умолчанию) и перезапустите контейнер:

```
AI_ENABLED=true
AI_PROVIDER=ollama
AI_MODEL=qwen2.5:7b
```

Адрес `AI_BASE_URL` задавать не нужно: внутри Docker бот сам обращается к Mac по `host.docker.internal:11434`.

**4. Проверьте связь** — команда покажет, что именно не так (не запущена Ollama, не скачана модель, не хватает
памяти), и прогонит три пробных поста:

```bash
docker compose exec lalascaner python -m lalascaner ai-check
```

При запуске бот тоже пишет в лог `ИИ готов` или `ИИ НЕДОСТУПЕН: <причина>` (`docker compose logs`).

**Как это работает.** Бот не ждёт медленную модель: сначала правила разбирают всё мгновенно, и сделки приходят сразу. Потом ИИ фоном «дорабатывает» сомнительное — сначала посты Telegram, затем свежие объявления lalafo (за последние 3 дня; старый хвост каталога остаётся на правилах, иначе слабый Mac считал бы сутками). Сколько ещё ждёт ИИ, видно в `/stats`. Ответ модели жёстко ограничен JSON-схемой (structured outputs Ollama) — небольшая
модель физически не может вернуть невалидный JSON или лишние поля. Пачка — 4 поста, пачки идут по одной
(локальная модель параллельно не ускоряется). Первая пачка после запуска дольше: модель загружается в память.
На результаты ИИ бот доверяет чуть меньше, чем Claude, поэтому по ним чуть строже фильтруются уведомления.
Batch API есть только у Claude.

### Другие бесплатные варианты

`AI_PROVIDER=openai` подключает любой сервер с OpenAI-совместимым `/chat/completions` — без установки
чего-либо на Mac:

| Вариант | Стоимость | `AI_BASE_URL` | `AI_MODEL` (пример) |
|---|---|---|---|
| **Groq** ([console.groq.com](https://console.groq.com)) | бесплатный тариф с лимитами, очень быстро | `https://api.groq.com/openai/v1` | `llama-3.3-70b-versatile` |
| **OpenRouter** ([openrouter.ai](https://openrouter.ai)) | есть модели с бесплатным тарифом (`:free`) | `https://openrouter.ai/api/v1` | `meta-llama/llama-3.1-8b-instruct:free` |

Ключ провайдера — в `AI_API_KEY`. Бесплатные тарифы ограничивают число запросов: если лимит исчерпан, бот
подождёт и повторит позже.

## Установка и запуск

### Mac одной командой (рекомендуется)

Нужны только [Docker Desktop](https://www.docker.com/products/docker-desktop/) (запущенный) и Homebrew.
Токен бота — от [@BotFather](https://t.me/BotFather). Затем:

```bash
git clone git@github.com:naurner/lalascaner.git
cd lalascaner
bash scripts/mac-setup.sh
```

Скрипт сам: обновит код, настроит `.env` (спросит токен, если его нет), поставит и запустит Ollama,
подберёт модель ИИ по объёму памяти Mac и запустит бота в Docker. Модель для разбора — не любая уже
скачанная, а та, что по размеру подходит машине: на Mac с 8 ГБ памяти модель весом 4+ ГБ (например,
`llama3.1`, 4,9 ГБ) вместе с macOS и Docker не поместится и будет наглухо тормозить — вместо нее скрипт
скачает лёгкую `qwen2.5:3b` (1,9 ГБ); на 16 ГБ и больше возьмёт то, что уже стоит, или `qwen2.5:7b`.
Конкретную модель — в обход этой проверки — можно задать так: `MODEL=qwen2.5:7b bash scripts/mac-setup.sh`.
Запускать скрипт можно повторно — например, после `git pull`.

### Docker вручную

```bash
git clone git@github.com:naurner/lalascaner.git
cd lalascaner
cp .env.example .env
```

Откройте `.env` в любом редакторе (`nano .env`) и впишите `BOT_TOKEN` (и, при желании, ИИ — см. разделы
выше), затем запустите:

```bash
docker compose up -d --build
```

Бот запускается в фоне и переживёт перезагрузку Mac (`restart: unless-stopped`). База лежит в `./data` —
удаление контейнера её не тронет. Полезные команды:

```bash
docker compose logs -f
```
```bash
docker compose exec lalascaner python -m lalascaner backfill all
```
```bash
docker compose exec lalascaner python -m lalascaner stats
```

Обновить после `git pull`:
```bash
docker compose up -d --build
```

Остановить:
```bash
docker compose down
```

Чтобы контейнер поднимался при включении Mac, в Docker Desktop → Settings → General включите
«Start Docker Desktop when you log in».

## Обновление кнопкой в боте

После установки код можно обновлять прямо из Telegram, без захода на сервер: кнопка **🔄 Обновить с
GitHub** (или `/update`) сама делает `git pull` и перезапускает бота. В ответ бот присылает список
новых коммитов и либо перезапускается сам (обычные изменения кода), либо просит один раз выполнить
`docker compose up -d --build` на сервере — это нужно, только когда поменялись зависимости
(`pyproject.toml`) или сам `Dockerfile`, что бывает редко.

Работает это за счёт того, что весь репозиторий смонтирован внутрь контейнера как есть (а не только
скопирован при сборке образа) и установлен в режиме `pip install -e .` — новый код с GitHub становится
видимым сразу после `git pull`, без пересборки.

**Разово после этого обновления** нужно обновиться через терминал, как раньше (`git pull` +
`bash scripts/mac-setup.sh` или `docker compose up -d --build`) — кнопки ещё не существовало в коде,
который уже запущен. Все следующие обновления — уже кнопкой.

### Вручную (Python)

Нужен Python 3.11+.

```bash
python -m venv .venv
```

```bash
.venv/bin/pip install -e ".[dev]"
```

(Windows: `.venv\Scripts\python -m pip install -e ".[dev]"`)

Скопируйте `.env.example` в `.env`, впишите `BOT_TOKEN` (создайте бота у [@BotFather](https://t.me/BotFather)).
ИИ по умолчанию выключен — ничего больше не нужно; включить его см. разделы выше.

Первичная загрузка базы (lalafo ~10–15 минут, Telegram ~2 минуты):

```bash
.venv/bin/python -m lalascaner backfill all
```

Основной режим — бот + сбор + разбор + уведомления по расписанию:

```bash
.venv/bin/python -m lalascaner run
```

Напишите боту `/start` — вы станете владельцем (или укажите свой ID в `BOT_ALLOWED_USERS`).

Большую очередь при `AI_PROVIDER=claude` можно заранее прогнать через Batch API (в режиме `run` это
происходит само):

```bash
.venv/bin/python -m lalascaner classify --batch-api
```

## Стоимость ИИ

`AI_PROVIDER=openai` (Ollama/Groq/OpenRouter) — бесплатно, см. раздел выше. На Claude пачка из 10 постов
≈ 5–6 тыс. входных токенов (из них ~3 тыс. — кэшированный промпт) и ~3 тыс. выходных: около $0.08–0.10 на
`claude-opus-5` и около $0.02 на `claude-haiku-4-5`; через Batch API — вдвое меньше. Модель задаётся в
`AI_MODEL`, расход виден в `/stats`.

## Тесты

```bash
.venv\Scripts\python -m pytest
```

Фикстуры в `tests/fixtures` — реальные ответы lalafo и Telegram.

## Ограничения

- Только публичные Telegram-каналы и группы.
- lalafo ограничивает частоту запросов (код 490) — клиент сам выдерживает паузы.
- Без ключа ИИ сложные посты (прайс-листы, смешанные «продам/куплю») разбираются частично.
